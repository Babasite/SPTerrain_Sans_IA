Différence avec autres langages (ici PHP)

Variables et Types

Exécuter un fichier python fichier.py php fichier.php ❌ Non Les deux langages peuvent être exécutés depuis un terminal.
Afficher du contenu print("Bonjour") echo "Bonjour"; ⚠️ Différent Python utilise principalement print() pour afficher une valeur.
Déclarer une variable, fin d'instruction age = 25 $age = 25; ⚠️ Différent Pas de $ devant les variables Python.
Le point-virgule n'est généralement pas nécessaire en Python.
Type int dans les deux langages.
Commentaire # commentaire // commentaire (ou # aussi) ❌ Non Python utilise #. PHP accepte aussi #.
Chaîne de caractères nom = "Paul" $nom = "Paul"; ❌ Non Le texte est placé entre guillemets.
Booléen vrai,faux True, False true, false ⚠️ Différent Python impose une majuscule.
Absence de valeur None null ⚠️ Différent None représente l'absence de valeur en Python.
Connaître le type type(age) gettype($age) ❌ Non Permet d'identifier le type d'une valeur.
Convertir int("25"), float("3.5"), str(25) (int) "25", (float) "3.5",
(string) 25		 ❌ Non Transforme ou convertit une valeur compatible.
Opérations (Addition, Soustraction, Multiplication, Division) a + b $a + $b ❌ Non Même opérateur.
Division entière a // b intdiv($a, $b) ⚠️ Différent Python arrondit vers le bas ; PHP tronque vers zéro.
Modulo a % b $a % $b ❌ Non Calcule le reste d'une division. Le signe peut différer pour les nombres négatifs.
Puissance 2 ** 3 2 ** 3 ❌ Non Calcule 2 puissance 3, soit 8.
Concaténation "Bon" + "jour" "Bon" . "jour" ⚠️ Différent Python utilise + pour assembler deux chaînes.
Insérer une variable dans du texte f"Bonjour {nom}" "Bonjour $nom" ⚠️ Différent Les f-strings permettent d'insérer des expressions dans une chaîne Python.

Listes et Tuples (Pareil mais une liste peut être modifiée, un tuple ne peut pas être modifié après sa création)

Créer une liste liste = [1, 2, 3] $liste = [1, 2, 3]; ❌ Non Une liste Python ressemble à un tableau indexé PHP.
Liste avec plusieurs types [1, "Paul", True] [1, "Paul", true] ❌ Non Les listes Python peuvent contenir différents types.
Accéder à un élément liste[0] $liste[0] ❌ Non Le premier élément possède l'indice 0.
Modifier un élément liste[0] = 5 $liste[0] = 5; ❌ Non Remplace la valeur à l'indice indiqué.
Dernier élément liste[-1] $liste[array_key_last($liste)] ⚠️ Différent Python permet d'utiliser directement un indice négatif.
Avant-dernier élément liste[-2] $liste[count($liste)-2] ⚠️ Différent L'exemple PHP suppose des indices numériques consécutifs commençant à zéro.
Ajouter un élément liste.append(4) $liste[] = 4; ❌ Non Ajoute une valeur à la fin de la liste.
Ajouter plusieurs éléments liste.extend([4, 5]) array_push($liste, 4, 5); ❌ Non Ajoute plusieurs valeurs à la liste existante.
Insérer un élément liste.insert(1, 10) array_splice($liste, 1, 0, [10]); ❌ Non Insère une valeur à une position précise.
Supprimer par valeur liste.remove(2) array_search() + unset() ⚠️ Différent Python supprime la première occurrence. En PHP, il faut rechercher et vérifier la clé avant de supprimer.
Supprimer le dernier élément liste.pop() array_pop($liste) ❌ Non Supprime et renvoie le dernier élément.
Supprimer à un indice liste.pop(1) array_splice($liste, 1, 1) ❌ Non Supprime l'élément à la position indiquée.
Supprimer avec del del liste[0] unset($liste[0]); ⚠️ Différent Python décale les indices suivants ; unset() ne réindexe pas automatiquement.
Compter les éléments len(liste) count($liste) ❌ Non Renvoie le nombre d'éléments.
Trier une liste liste.sort() sort($liste); ❌ Non Trie directement la collection.
Inverser une liste liste.reverse() $liste = array_reverse($liste); ⚠️ Différent reverse() modifie la liste Python ; array_reverse() renvoie un nouveau tableau PHP.
Rechercher un indice liste.index(3) array_search(3, $liste) ❌ Non Recherche la première occurrence. Python lève une erreur si elle est absente.
Compter les occurrences liste.count(3) array_count_values($liste)[3] ?? 0 ❌ Non Compte les valeurs égales à 3. L'exemple PHP convient aux valeurs entières.
Vérifier une présence 3 in liste in_array(3, $liste) ❌ Non Renvoie un booléen. Les règles de comparaison diffèrent selon le langage.
Extraire une partie de liste liste[1:3] array_slice($liste, 1, 2) ⚠️ Différent Le slicing Python exclut l'indice de fin.
Créer un tuple coord = (10, 20) Pas de type tuple natif ✅ Oui Un tuple est une séquence immuable.
Accéder à un tuple coord[0] $coord[0] ❌ Non L'accès ressemble à celui d'un tableau indexé.
Modifier un tuple Impossible directement Tableau PHP modifiable ✅ Oui Un tuple ne permet pas de remplacer ses éléments.

Dictionnaires

Créer un dictionnaire d = {"nom": "Paul"} $d = ["nom" => "Paul"]; ⚠️ Différent Un dictionnaire Python ressemble à un tableau associatif PHP.
Dictionnaire vide d = {} $d = []; ⚠️ Différent Python utilise des accolades pour créer un dictionnaire vide.
Accéder à une valeur d["nom"] $d["nom"] ❌ Non On récupère la valeur grâce à sa clé.
Ajouter une clé d["age"] = 25 $d["age"] = 25; ❌ Non Ajoute une paire clé-valeur.
Modifier une valeur d["age"] = 30 $d["age"] = 30; ❌ Non Remplace la valeur associée à une clé existante.
Supprimer une clé del d["age"] unset($d["age"]); ❌ Non Supprime la paire clé-valeur.
Récupérer les clés d.keys() array_keys($d) ❌ Non Python renvoie une vue dynamique, PHP un tableau.
Récupérer les valeurs d.values() array_values($d) ❌ Non Permet de parcourir les valeurs.
Récupérer clés et valeurs d.items() foreach ($d as $k => $v) ⚠️ Différent items() fournit les couples clé-valeur.
Lire une clé sans erreur d.get("nom") $d["nom"] ?? null ⚠️ Différent get() renvoie None par défaut si la clé n'existe pas.
Supprimer et récupérer d.pop("nom") $v = $d["nom"]; unset($d["nom"]); ⚠️ Différent pop() renvoie la valeur supprimée. La clé doit exister dans cet exemple.
Vider un dictionnaire d.clear() $d = []; ❌ Non Supprime toutes les paires clé-valeur.
Vérifier une clé "nom" in d array_key_exists("nom", $d) ❌ Non Vérifie l'existence de la clé, même si sa valeur est null ou None.

Conditions

Condition if if age >= 18: if ($age >= 18) { ... } ⚠️ Différent Python utilise : et l'indentation au lieu des accolades.
Sinon else: else { ... } ⚠️ Différent Même principe, syntaxe différente.
Sinon si elif age == 18: elseif ($age == 18) { ... } ⚠️ Différent Python utilise elif.
Égalité a == b $a == $b ⚠️ Différent La syntaxe est identique, mais PHP peut convertir les types.
Différence a != b $a != $b ⚠️ Différent Même symbole, règles de comparaison parfois différentes.
Supérieur a > b $a > $b ❌ Non Compare deux valeurs compatibles.
Inférieur a < b $a < $b ❌ Non Compare deux valeurs compatibles.
ET logique a and b $a && $b ⚠️ Différent Python utilise le mot and.
OU logique a or b $a || $b ⚠️ Différent Python utilise le mot or.
NON logique not a !$a ⚠️ Différent Python utilise not pour inverser une condition.
Indentation 4 espaces recommandés Accolades pour délimiter les blocs ✅ Oui L'indentation fait partie de la syntaxe Python.

Boucles

Boucle for for x in liste: foreach ($liste as $x) { ... } ⚠️ Différent Le for Python ressemble souvent au foreach PHP.
Boucle avec range for i in range(5): for ($i=0; $i<5; $i++) { ... } ⚠️ Différent range(5) produit les entiers de 0 à 4.
Boucle while while x < 10: while ($x < 10) { ... } ⚠️ Différent Répète un bloc tant que la condition est vraie.
Arrêter une boucle break break; ❌ Non Interrompt immédiatement la boucle.
Passer à l'itération suivante continue continue; ❌ Non Ignore le reste de l'itération en cours.
Parcourir avec les indices enumerate(liste) foreach ($liste as $i => $v) ⚠️ Différent enumerate() produit un indice et une valeur.

Fonctions

Déclarer une fonction def bonjour(): function bonjour() { ... } ⚠️ Différent Python utilise def.
Appeler une fonction bonjour() bonjour(); ❌ Non Même principe.
Paramètre def bonjour(nom): function bonjour($nom) { ... } ⚠️ Différent Les paramètres Python ne commencent pas par $.
Retourner une valeur return resultat return $resultat; ❌ Non Renvoie le résultat d'une fonction.
Paramètre par défaut def f(x=10): function f($x=10) { ... } ❌ Non Une valeur est utilisée si l'argument est omis.
Plusieurs valeurs de retour return a, b return [$a, $b]; ⚠️ Différent Python renvoie ici un tuple.
Fonction anonyme lambda x: x * 2 fn($x) => $x * 2 ⚠️ Différent Permet de définir une petite fonction sans nom.

Erreurs

Gérer une exception try: try { ... } ⚠️ Différent Permet de surveiller un bloc susceptible de provoquer une erreur.
Intercepter une exception except ValueError: catch (ValueError $e) { ... } ⚠️ Différent Python utilise except. ValueError est une exception Python, pas une classe PHP standard.
Bloc finally finally: finally { ... } ❌ Non Exécute un bloc de nettoyage après try.
Déclencher une exception raise ValueError("Erreur") throw new Exception("Erreur"); ⚠️ Différent Python utilise raise, PHP utilise throw.
Erreur de syntaxe SyntaxError ParseError ❌ Non Signale une erreur de syntaxe dans le programme.
Variable inconnue NameError Variable indéfinie : avertissement ⚠️ Différent Python lève notamment NameError pour un nom non défini.
Indice inexistant IndexError Avertissement pour clé inexistante ⚠️ Différent Python lève une exception lors d'un accès hors limites.
