Métaphores

Informatique Métaphore de l'immeuble 🏢 Métaphore humaine 🧍
Ordinateur L'immeuble 🏢 Le corps humain 🧍
Adresse IP (127.0.0.1) L'adresse de l'immeuble 📍 Sa propre identité
localhost Le nom qui désigne ton propre immeuble 📍 Le « soi »
Port (8000) Le numéro de porte 🚪 Les récepteurs cutanés du toucher
Logiciel serveur La personne qui travaille derrière la porte 👨‍💻 Un organe spécialisé
Serveur local Une personne qui travaille dans ton propre immeuble 🏠 Les organes de son propre corps
Serveur distant (site Internet) Une personne qui travaille dans un autre immeuble, accessible à distance 🌍 Une banque d'organes
Navigateur Le visiteur qui demande un service 🙋 Les yeux et le cerveau 👁️
Requête HTTP La demande du visiteur 📩 Un message hormonal
Réponse HTTP Ce que lui remet le serveur 📦 La réponse de l'organe cible
URL L'adresse complète indiquant l'immeuble, la porte éventuelle et la ressource recherchée 🗺️ La localisation anatomique d'une cible
DNS L'annuaire qui permet de retrouver l'adresse d'un immeuble à partir de son nom 📖
HTTPS Un échange sécurisé entre le visiteur et l'immeuble 🔒
base de données La salle des archives où sont conservées les informations 🗄️ La mémoire à long terme 🧠
Fichier HTML (.html) Le plan d'aménagement d'une pièce : murs, portes, tables, chaises… 🏗️ Le plan anatomique du corps
Fichier CSS (.css) Le décorateur qui choisit les couleurs, les dimensions, les espacements et la disposition 🎨 La pigmentation et l'apparence physique
Fichier JavaScript (.js) L'électricien qui installe les boutons, les automatismes et les interactions ⚡ Les réflexes et les mouvements
Fichier PHP (.php) L'employé qui travaille en coulisses, traite les demandes et prépare les réponses 👨‍💼
Fichier JSON (.json) Une fiche contenant des informations organisées selon un format précis 📋
Fichier Python (.py) Un ensemble d'instructions qu'un employé sachant lire le Python peut exécuter 🐍 Les instructions génétiques 🧬
Fichier SQL (.sql) Des instructions permettant de consulter ou modifier les archives 🗄️
Fichier Markdown (.md) Un document rédigé avec des conventions simples pour organiser titres, listes et textes 📝
Fichier de configuration (.env) Une fiche contenant des paramètres propres au fonctionnement de l'immeuble ⚙️ Les paramètres physiologiques
Fichier image (.png, .jpg) Les photographies et illustrations accrochées aux murs 🖼️ Un souvenir visuel
Fichier PDF (.pdf) Un document prêt à être consulté ou imprimé 📄
Dossier Une armoire contenant plusieurs documents 📂 Un compartiment cellulaire
Chemin d'accès Les indications permettant de retrouver un document dans l'immeuble 🧭 Bras → avant-bras → poignet
Requête Une demande adressée à un employé pour obtenir un document, une information ou une action 📩 Un signal nerveux ou hormonal
Framework Une structure d'immeuble préfabriquée, avec des équipements déjà installés et des règles de construction à respecter 🏗️ Le squelette et les articulations 🦴
Git Un registre conservant les différentes versions des plans de l'immeuble, permettant de comparer les modifications et de retrouver un ancien plan 📚
Terminal Un guichet permettant de transmettre des ordres écrits et de lire les réponses des employés ⌨️ La bouche pour commander, les oreilles pour recevoir
Linux Le gestionnaire central de l'immeuble qui coordonne les équipements, répartit les ressources et contrôle les accès ⚙️ Le système nerveux central 🧠
Variable Une boîte étiquetée dont le contenu peut changer 📦 La glycémie, la température corporelle
Objet Un ascenseur possédant des caractéristiques et des actions propres 🛗 Un organe avec ses caractéristiques et ses fonctions
Tableau (Array) Une rangée de casiers numérotés contenant chacun un élément Les vertèbres de la colonne vertébrale
Condition Si la température est trop basse, le chauffage se déclenche Si la glycémie augmente, sécrétion d'insuline
Boucle Un employé qui répète une tâche plusieurs fois 🔁 Le cycle cardiaque
Méthode Une action propre à un équipement, comme ouvrir les portes d'un ascenseur La contraction du cœur
Fonction Une tâche définie qu'un employé peut effectuer chaque fois qu'on la lui demande La filtration rénale
Interpolation Une lettre préécrite dans laquelle on insère automatiquement le nom du destinataire
Programmation événementielle Une sonnette qui déclenche une action lorsqu'un visiteur appuie dessus 🔔 Le réflexe de retrait
Programmation séquentielle Un employé qui réalise les étapes d'une tâche les unes après les autres La succession des étapes de la déglutition
Formulaire Une fiche que le visiteur doit remplir avant de la remettre à l'accueil 📋
Hooks Des points prévus dans le fonctionnement de l'immeuble pour déclencher des actions supplémentaires
Pre Une vérification effectuée avant de commencer une tâche La salivation avant l'ingestion d'aliments
Post Une action effectuée après la réalisation d'une tâche
Programmation orientée objet (POO) Un immeuble organisé en équipements autonomes possédant chacun leurs caractéristiques et leurs actions Les organes avec leurs structures et leurs fonctions
Client GUI Un panneau de commande avec des boutons, des écrans et des menus
API Un guichet proposant des services précis avec des règles pour les demander Les récepteurs membranaires
Librairie (Bibliothèque) Une boîte à outils déjà disponibles que les employés peuvent utiliser 🧰
NPM Un gestionnaire qui récupère, installe et met à jour les outils nécessaires aux employés
Stack L'ensemble des matériaux, équipements et outils utilisés pour construire et faire fonctionner l'immeuble
Runtime Un atelier équipé du personnel et du matériel nécessaires pour exécuter des instructions Le milieu intracellulaire permettant les réactions biochimiques
Gitignore (.gitignore) Une liste des documents que l'archiviste ne doit pas ajouter au registre des versions
Variables d'environnement (env) Les réglages propres à chaque immeuble, utilisés par ses employés Les paramètres du milieu intérieur
Package Une mallette contenant plusieurs outils et leurs notices d'utilisation 📦
MongoDB Une salle d'archives contenant des fiches qui peuvent avoir des rubriques différentes
Mongoose Un intermédiaire qui organise, vérifie et transmet les fiches à la salle d'archives MongoDB
SQL Le langage utilisé pour donner des instructions à l'archiviste
ETL Un employé qui récupère des documents, les réorganise puis les range dans une nouvelle salle d'archives
CSV (.csv) Un registre dont les informations sont rangées en lignes et séparées par des délimiteurs
Réseau TCP Un système de livraison qui vérifie la réception des colis, renvoie ceux qui manquent et les remet dans le bon ordre
Réseau IP Un réseau de routes reliant des immeubles possédant chacun une adresse Le réseau vasculaire
Routeur Un agent d'orientation qui dirige les colis vers le prochain chemin menant à leur destination
DHCP Un service qui attribue automatiquement une adresse temporaire aux nouveaux arrivants
Nmap Un inspecteur qui repère les immeubles accessibles, leurs portes ouvertes et les services disponibles
SMTP Le service postal chargé d'expédier les lettres 📤
IMAP Un service permettant de consulter et d'organiser les lettres conservées au bureau de poste 📥
Proxy Un intermédiaire qui transmet les demandes du visiteur et lui rapporte les réponses
VPS Un appartement privé et indépendant situé dans un immeuble partagé avec d'autres occupants
WSL2 Un atelier Linux aménagé à l'intérieur d'un immeuble Windows
GNOME L'aménagement visuel des espaces permettant aux occupants d'utiliser les équipements de l'immeuble
Ubuntu Un immeuble équipé du gestionnaire Linux, de ses outils et de ses services
Shell L'employé du guichet qui interprète les ordres et organise leur exécution Les centres nerveux du langage
Hyperviseur Un gestionnaire qui partage les ressources d'un immeuble entre plusieurs logements virtuels indépendants
XSS Une fausse instruction glissée dans un document officiel et exécutée par le visiteur qui le consulte
Architecture MVC Une organisation en trois services : les archives et leur gestion (Modèle), l'espace visible du visiteur (Vue) et l'employé qui coordonne les demandes (Contrôleur)
PyScript Un atelier installé dans l'espace des visiteurs permettant d'exécuter directement des instructions Python
Flask Une petite structure préfabriquée permettant d'aménager rapidement un service web
